# Stash

Bookmark vault: accounts, collections, tags, instant search, favorites, public share pages, bookmarks import (browser HTML or JSON), export, dead-link checker, plans (Free live, Pro draft) and an admin dashboard with audit log.

Live: https://stools.mahmodsalah.workers.dev

Cloudflare Worker + SQLite Durable Object + static assets, no build step. Deploy: `npx wrangler deploy`.
